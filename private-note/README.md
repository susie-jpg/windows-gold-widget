# Windows 隐私便签

把文章粘贴到窗口里，用于本地阅读或会议前准备。窗口会调用 Windows `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，请求系统在屏幕捕获、录屏和部分会议投屏中排除该窗口。

## 使用

1. 安装 Python 3（含 Tkinter）。
2. 双击 `Start.vbs`。
3. 直接在窗口中按 `Ctrl+V` 粘贴文章。
4. `Ctrl+S` 保存，`Esc` 退出；拖动顶部移动窗口。
5. 拖动右下角可调整窗口大小；`Ctrl+Shift+H` 全局隐藏/恢复窗口（隐藏后不会退出程序）。

## 限制

这是 Windows 提供的捕获排除请求，通常对系统截图、录屏和常见会议软件的窗口捕获有效，但不能保证所有投屏方式都遵守它。若会议软件捕获的是整个显示器、使用驱动级采集，或软件自身忽略该属性，内容可能仍被投出。发布会前请用目标会议软件做一次实际测试，并把状态显示为“捕获排除：已启用”作为前置检查。
